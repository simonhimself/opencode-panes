# 03: Put current Artifacts first

**What to build:** Make Inventory prioritize current Artifacts and routine actions while keeping exceptional recovery and destructive operations available through deliberate disclosure.

**Blocked by:** None (can start immediately).

**Status:** ready-for-human

- [x] Current Artifacts appear before Legacy history.
- [x] Legacy history is collapsed by default and shows enough summary information to remain discoverable.
- [x] Recovery, rotation, adoption, reconnect, and deletion controls are hidden behind Manage rather than repeated on every Artifact card.
- [x] Existing confirmations and authorization boundaries for exceptional operations remain unchanged.
- [x] Inventory UI tests cover ordering, Legacy disclosure, and access to managed operations.
