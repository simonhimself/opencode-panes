# Domain Docs

This repository uses a single-context domain layout.

Before exploring, read `CONTEXT.md` when it exists and relevant ADRs under `docs/adr/`. If they do not exist, proceed without requesting them.

Use terminology defined in `CONTEXT.md`. Flag any proposed change that contradicts an existing ADR instead of silently overriding it.

Expected layout:

```text
/
|-- CONTEXT.md
`-- docs/adr/
```
