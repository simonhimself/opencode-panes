# OpenCode Panes v0.3

Panes is an OpenCode plugin with a simple, private Cloudflare artifact library.
Create ordinary local files, upload a browser-ready snapshot, and choose what to
share from the dashboard.

## Highlights

- Two plugin tools: `artifact_upload` and `artifact_dashboard`.
- Direct private uploads of HTML, SVG, and browser-ready folders, without local
  Drafts, Finalize, manifests, or version directories.
- A light visual dashboard with project navigation, previews, search, and clear
  Private, Shared, and Expired states.
- Immutable cloud versions. A new upload never changes the shared version.
- Stable active share links when you explicitly update the selected version.
- No expiry by default, with optional 1-, 7-, or 30-day durations.
- Explicit unpublish and cloud-only deletion; local source files stay untouched.
- Browser-built JavaScript works in isolated previews and gallery thumbnails.

## Installation

Build and install the plugin from this release:

```sh
npm install
npm run install:plugin
```

Configure `OPENCODE_PANES_API_URL` and `OPENCODE_PANES_UPLOAD_KEY` for your own
deployment, then restart the OpenCode process. Creating a new conversation alone
does not reload the plugin. One owner per deployment; other users host their own
Cloudflare instance. The plugin is not published to the npm registry.

See the [README](../../README.md) and [manual test guide](../manual-testing.md)
for usage, setup, and copy-ready test prompts.

## Breaking changes

This intentionally replaces the v0.1/v0.2 protocols. Creator links, managed local
history, reconnect/adoption, and source-string APIs are retired. Existing cloud
artifacts and links are not migrated into the new library. Raw React, Markdown,
Mermaid, and code renderer entries are no longer supported; build or export to
browser-ready HTML/SVG locally instead.

Deployments need migration `0011_simple_library.sql`, a `PANES_UPLOAD_KEY`
Worker secret, and owner Access protection for `/inventory*` and `/api/library*`.
Upload and public capability routes must remain outside the owner login gate.
Keep the R2 bucket private. Old database migrations remain unchanged.

## Verification and boundaries

- 174 automated tests, workspace type checks, formatting, web/plugin builds,
  standalone plugin smoke, and Cloudflare deployment dry-run passed during
  implementation verification.
- Real local plugin-to-Worker acceptance covers upload retries, exact text/binary
  bytes, assets, independent versions, sharing, revocation, and deletion.
- Desktop/mobile browser acceptance includes script-built previews, publishing,
  copying, public viewing, unpublishing, and sandbox parent-DOM isolation.
- Mobile Lighthouse snapshot scored 100 for accessibility and best practices.

Uploads are bounded to 500 files, 25 MiB per file, and 100 MiB per snapshot.
Panes serves browser artifacts, not backends or cloud framework builds. HTTPS
resources are allowed subject to browser CORS and sandbox restrictions. Filename
exclusions are not a general secret scanner. Uncommitted uploads remain available
for retry; automatic abandoned-upload expiry is not implemented.
