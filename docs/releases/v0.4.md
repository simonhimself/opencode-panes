# OpenCode Panes v0.4

Moves the plugin to the OpenCode 2 plugin API and adds automatic cleanup of
abandoned uploads. The two tools, `artifact_upload` and `artifact_dashboard`,
keep their inputs and results.

## Breaking changes

- The plugin supports OpenCode 2.0.18 or newer only. OpenCode 1 plugin hosts
  are no longer supported.
- OpenCode 2 checks the `artifact_upload` permission before each upload runs.
  The plugin no longer raises its own prompt, so the permission is no longer
  scoped to the API origin. Configure it with OpenCode permission rules.
- OpenCode 2 loads plugins listed in `opencode.json` only from a package
  directory, not a single file. Reinstall with `OPENCODE_PANES_PACKAGE_DIR`
  if you pass plugin options such as a `{file:...}` upload-key reference.

## Plugin

- Registers its tools through a V2 `setup()` with `ctx.tool.transform`.
- Resolves upload sources against the project root reported by OpenCode, so
  project and artifact identities match those created by v0.3.
- Drops `@opencode-ai/plugin`. The bundle stays standalone with no runtime
  dependencies and shrinks from about 612 KB to 339 KB.
- The installer gains `OPENCODE_PANES_PACKAGE_DIR` to write a package directory
  (`index.js` and `package.json`) for configured plugin entries. The default
  still writes `plugins/opencode-panes.js` for auto-discovery.

## Worker

Unfinished uploads older than seven days now expire, and the existing hourly
cron removes their stored files in bounded batches. Committed versions are never
eligible. See [storage cleanup](../storage-cleanup.md).

## Updating

1. Rebuild and reinstall the plugin, then restart OpenCode:

   ```sh
   npm install
   npm run install:plugin
   ```

   For a configured entry with options, install a package directory instead and
   point the entry's `package` at it. See
   [plugin configuration](../OPERATIONS.md#plugin-configuration).

2. For abandoned-upload cleanup, apply migration
   `0012_abandoned_upload_cleanup.sql`, then deploy the Worker. The upload API
   is unchanged, so the new plugin also works with a v0.3.1 Worker until then.

## Verification

- 196 automated tests cover the Worker, client, contracts, plugin, and installer.
- Workspace type checks, formatting, web and plugin builds, and the standalone
  plugin smoke test pass.
- On OpenCode 2.0.18, the installed package directory loaded as
  `opencode-panes`, received its options including a resolved `{file:...}`
  upload key, and completed a private upload to the hosted Worker.

The `artifact_upload` permission gate was not observed directly: the test
configuration allows all tools, and OpenCode 2 does not log permission checks.
